# Точки ужаса

Атмосферный психологический хоррор от первого лица. Детская игра «соедини точки»
превращена в источник паники.

Мир — чернильные линии в полной темноте. Интерактив — светящиеся неоновые точки.
Замкнутый круг: страшно → руки дрожат → линия кривится → ошибка → мир становится
хуже → ещё страшнее.

## Как запустить

Скачать `dots_of_terror_3d.html` и открыть двойным щелчком в браузере.
Больше ничего не нужно: ни установки, ни интернета, ни единого внешнего файла —
геометрия, звук и лабиринт считаются на лету.

## Управление

| Клавиши | Действие |
|---|---|
| W A S D | ходьба |
| ← → или мышь | поворот камеры (Shift — быстрее) |
| Q | развернуться кругом |
| Пробел | вспышка палочки, а в захвате — вырываться (жать, а не зажимать) |
| E | взять палочку, читать книжки |
| Мышь / тачпад | соединять точки на полотне |
| − = | чувствительность камеры |

Мыши может не быть — играется и на тачпаде.

## Что внутри

- **Три фазы страха.** Сначала монстра нет как тела: он движется внутри камня
  и только слышен. Потом шум игрока отбирает ему слух. И лишь затем монстр
  выходит из стены.
- **Шесть полотен**, на каждом меняется правило, а не цифра: пропадают номерки,
  доска гаснет, точки начинают плыть. Фигуры берутся из пула в двадцать штук —
  каждый забег свои.
- **Лабиринт новый на каждый забег.**
- **Финал.** Выхода нет. Есть стена, и дверь надо нарисовать, пока оно идёт по коридору.
